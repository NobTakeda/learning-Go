### A Tour of Go
### 6-9~: sync.Mutex
+ Goのmapはスレッドセーフではなく、複数のゴルーチンから同時に読み書きするとデータ破損や実行時エラーになる
+ 同時に1つだけアクセスさせる仕組みがmutex（排他制御）
+ `import("sync")`で使う
+ `Lock()`：鍵をかける（他のゴルーチンはここで待たされる）
+ `Unlock()`：鍵を外す（待っていた次のゴルーチンが通れる）
```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type SafeCounter struct {
	mu sync.Mutex
	v  map[string]int
}

func (c *SafeCounter) Inc(key string) {
    c.mu.Lock()
    c.v[key]++
    c.mu.Unlock()
}
```
